# Overview

The main story is the weekend's dominant AI conversation: "The Unreasonable Effectiveness of HTML," a ~10-million-view essay by Tariq of Anthropic's Claude Code team proposing that agent users ditch markdown for HTML. Tariq's case: HTML carries far denser information (tables, CSS, SVG), is dramatically easier for humans to read than 100+-line markdown files, is easier to share as a link, supports two-way interaction (sliders, tweakable options), and is simply more fun — while markdown's editability advantage matters less now that Claude does the editing. Nathaniel Whittemore surveys the pushback (chiefly that HTML burns far more tokens) and The Smart Ape's synthesis — pick format by audience, life cycle, and horizon: markdown when Claude reads it, it's edited often, and it must last; HTML when humans read it, it's written once, and it's ephemeral.[^the-best-way-to-talk-to-your-agents-NNxGQw1uQHc]

Whittemore's own argument goes deeper: the debate matters because the atomic unit of knowledge work has shifted. In the agent era, the operator's job is not to finish the work but to stage the conditions under which the agent finishes it — living in a "liminal" in-between workspace of "mixed doneness," where some decisions are locked, some open, and some provisional. HTML's native features (tabs, progressive disclosure, color-coded status, expandable sections) can encode those states structurally, where markdown forces caveat-laden meta-commentary. Headlines cover Anthropic weighing a ~$50B pre-IPO round at $900B pre-money, the red-hot Cerebras IPO, TSMC's growth slowdown, Apple's preliminary Intel chip deal, micro data centers on new homes, and OpenAI's Codex Chrome plugin.[^the-best-way-to-talk-to-your-agents-NNxGQw1uQHc]

- Whittemore's handoff pain points: AI-written handoff docs present everything "as though it has been ordained from on high," forcing him to caveat that provisional decisions are still open — a calibration problem where overspecifying kills the agent's range and vagueness produces flailing or generic output.[^the-best-way-to-talk-to-your-agents-NNxGQw1uQHc]

# Takeaways

Whittemore concludes Tariq is right, but for a bigger reason than ease of reading or sharing: knowledge work is moving from producing the final output to managing the agent that produces it, and workers now spend most of their process in the liminal staging space that used to be merely transitional. The new core skill is calibrating how much structure to impose so the unstructured remainder is something the agent can productively resolve — and format debates like markdown-vs-HTML are early explorations of that modality, with context engineering being another slice of the same problem: giving the agent the context of the work process so far.[^the-best-way-to-talk-to-your-agents-NNxGQw1uQHc]

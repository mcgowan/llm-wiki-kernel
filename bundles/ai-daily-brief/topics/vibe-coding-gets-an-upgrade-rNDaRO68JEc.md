# Overview

Whittemore surveys a wave of releases from Anthropic, Lovable, Google, and others and argues the term "vibe coding" — coined by Andrej Karpathy just 14 months earlier — may already be outliving its usefulness, both because there is "increasingly nothing but vibe coding" and because the activity is less about coding than about multi-agent orchestration. The centerpiece is Anthropic's ground-up redesign of Claude Code in the desktop app, built explicitly for parallel work: a sidebar managing multiple sessions across repos, an integrated terminal and file editor, and a drag-and-drop workspace that turns the app into an "agent orchestration command center."[^vibe-coding-gets-an-upgrade-rNDaRO68JEc]

He also covers Anthropic's new Claude Code "routines" (templated agents triggered by GitHub events or API, running on Anthropic-managed cloud infrastructure), Lovable's desktop app and native payments, Google's AI Studio design previews and Chrome "Skills," and Microsoft's reported effort to build a safer enterprise version of Open Claw — all pointing to product convergence as coding becomes a core primitive of knowledge work.[^vibe-coding-gets-an-upgrade-rNDaRO68JEc]

# Key points

- Anthropic released a redesigned Claude Code desktop app "built for how agentic coding actually feels now — many things in flight and you in the orchestrator seat," per its announcement; Felix Riesberg called it "redesigned from the ground up for parallel work."[^vibe-coding-gets-an-upgrade-rNDaRO68JEc]
- Claude Code co-creator Kat Wu said the desktop app is now "the best way to kick off and manage multiple CC sessions across local and cloud in one place"; Riley Brown observed "Cursor, Codex, and Claude Code desktop app look exactly the same now," and Cursor 3 offered a similar interface earlier in the month.[^vibe-coding-gets-an-upgrade-rNDaRO68JEc]
- Complaints centered on usage limits: users mocked running multiple sessions when "people can barely run one session with Opus 4.6 without chewing through usage" — Whittemore calls throttling Anthropic's big new PR battle. Whittemore himself had the new app implode on one of his projects.[^vibe-coding-gets-an-upgrade-rNDaRO68JEc]
- Claude Code "routines" extend scheduled tasks: saved configurations (prompt, repos, connectors) triggered via GitHub event or API, executing on Anthropic-managed cloud so they "keep working when your laptop is closed"; The Register called them a dynamic cron job.[^vibe-coding-gets-an-upgrade-rNDaRO68JEc]
- Greg Eisenberg argued "the model is the commodity, the trigger is the product," predicting generational companies from mapping industry-specific triggers (a permit filed, usage dropping 40%, a deal untouched 14 days) to agent workflows.[^vibe-coding-gets-an-upgrade-rNDaRO68JEc]
- Lovable launched a desktop app (local MCPs, multi-project tracking, native shortcuts) and natural-language native payments; Linear COO Kristina Cordova noted "you're not vibe coding PCI level one," and CEO Antoine Osika said "it's never been easier to go from product to an actual business."[^vibe-coding-gets-an-upgrade-rNDaRO68JEc]
- Google added design previews to AI Studio's vibe-coding experience (Gemini generates custom themes while an app builds) and launched Skills in Chrome, a prompt-library-like feature for one-click Gemini workflows; Sundar Pichai said future search "would be an agent manager."[^vibe-coding-gets-an-upgrade-rNDaRO68JEc]
- The Information reported Microsoft is testing Open Claw-inspired features, with corporate VP Omar Shahine leading a team exploring it in an enterprise context, betting on a safer version via limited permissions and role siloing.[^vibe-coding-gets-an-upgrade-rNDaRO68JEc]
- Superblocks CEO Brad Menezes argued vibe-coding apps have become an enterprise attack vector — employees building apps on production data with no IT oversight — pitching Superblocks 2.0 as governed vibe coding; Whittemore suspects many supportive replies were undisclosed paid posts but endorses the underlying trend.[^vibe-coding-gets-an-upgrade-rNDaRO68JEc]

# Takeaways

Whittemore concludes that no single change was massive, but the trajectory is unmistakable: every lab — model labs and agent labs alike — is racing to make agentic coding apps useful 24/7 whether or not you are sitting in front of them, and products are converging because "coding to build things that do your work or help you do your work is becoming one of the core primitives of knowledge work." He predicts enterprise hardening of vibe coding will be one of the biggest building opportunities for the rest of 2026.[^vibe-coding-gets-an-upgrade-rNDaRO68JEc]
